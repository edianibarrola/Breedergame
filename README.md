# Breeder game — Web playtests

This public repository is reserved for approved compiled Unity Web playtest builds. Editable game source is maintained separately.

Version 0.3.0 is an offline habitat workshop built in Unity. Customize an enclosure's finish, wood, and bedding; add an upper chamber; assign breeder housing or sales display use; and expand the sanctuary to three bays. Existing bays keep their settings. The prototype uses 20 reusable Blender-authored parts, including a climate-control module.

Use **Style** for finishes, **Build** for expansion, and **Care** for each chamber's suitability. Tap a bay in the sanctuary to inspect it. Stacked bays have **View upper / View lower** controls so both chambers remain accessible. The overview uses a lower camera angle when stacks are present.

Comfort checks usable space, shelter/water, and climate equipment. Fit the basic equipment and let the 20-second playtest settling period finish. Settling continues while you are away. Paint and decorative choices do not affect readiness. Each chamber keeps its own care settings, and existing saved layouts migrate automatically.

This is an asset and layout playtest. Breeding gameplay, real inventory, upgrade costs, accounts, and player trading are still to come. The first workshop has a three-bay review limit with up to two adult chambers per bay. Cosmetic changes do not add housing capacity.

Settings save locally in the browser and do not synchronize between devices. Future online features require a separate backend; GitHub Pages serves the client only. Phone performance and touch behavior need real-device testing.
